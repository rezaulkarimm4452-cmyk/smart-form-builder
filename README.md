# 📝 স্মার্টফর্ম (SmartForm) - ডায়নামিক অনলাইন রেজিস্ট্রেশন ও অ্যাডমিন সিস্টেম

একটি সম্পূর্ণ ফুল-স্ট্যাক প্রজেক্ট যাতে রয়েছে গুগল ফর্মের মতো মডার্ন ফ্রন্টএন্ড ইউজার ফর্ম, শক্তিশালী ব্যাকএন্ড অ্যাডমিন প্যানেল, ডায়নামিক ফর্ম বিল্ডার এবং লোকাল SQLite ডাটাবেস।

---

## ✨ মূল সুবিধাসমূহ (Key Features)

1. **পাবলিক ইউজার সাইট (Public User Portal)**:
   - গুগল ফর্ম ও আধুনিক কার্ড ডিজাইনের সমন্বয়ে তৈরি।
   - লাইট থিম ও মার্জিত এমারেল্ড গ্রিন (`Emerald Green`) এক্সেন্ট কালার।
   - আবেদন সাবমিট করার পর ইউনিক কনফার্মেশন কোড (`REG-YYYYMMDD-XXXX`) জেনারেশন ও সামারি প্রিভিউ।
   - এক ক্লিকে কোড কপি এবং আরেকটি নতুন আবেদন করার সুবিধা।

2. **কাস্টম ড্রপডাউন মেনু (Custom Dropdown - No Browser Defaults)**:
   - ব্রাউজারের কোনো ডিফল্ট বা সনাতন ড্রপডাউন ব্যবহার করা হয়নি।
   - সম্পূর্ণ কাস্টমাইজড, মসৃণ অ্যানিমেশন, গ্রিন হাইলাইট ও টিকমার্ক যুক্ত ড্রপডাউন।
   - কিবোর্ড নেভিগেশন (Arrow Keys, Enter, Escape) ও সার্চ ফিল্টারিং সাপোর্ট।

3. **অ্যাডমিন প্যানেল (Admin Dashboard)**:
   - **আবেদন পর্যালোচনা (Submissions Overview)**:
     - সর্বমোট আবেদন সংখ্যা ও আজকের আবেদনের রিয়েলটাইম কাউন্টার।
     - যেকোনো নাম, কোড বা তথ্যের ভিত্তিতে লাইভ ইনস্ট্যান্ট সার্চ।
     - প্রতিটি আবেদনের পূর্ণাঙ্গ তথ্য (Modal View) দেখা ও প্রিন্ট করার সুবিধা।
     - এক ক্লিকে সকল আবেদনের তথ্য এক্সেল/CSV ফরম্যাটে ডাউনলোড (বাংলা ফন্ট সাপোর্ট সহ UTF-8 BOM)।
     - অপ্রয়োজনীয় আবেদন মুছে ফেলার সুবিধা।
   - **ডায়নামিক ফর্ম বিল্ডার (Dynamic Form Builder)**:
     - ফর্মের শিরোনাম ও নির্দেশনা পরিবর্তন।
     - নতুন ইনপুট ফিল্ড যোগ করা (Text, Email, Phone, Dropdown, Radio, Textarea, Number, Date)।
     - প্রতিটি ফিল্ডের টাইপ, প্লেসহোল্ডার, আবশ্যক (Required) শর্ত ও অপশন কাস্টমাইজেশন।
     - ফিল্ডগুলোর ক্রম বা পজিশন সহজে উপরে-নিচে (Up/Down) সাজানোর সুবিধা।
     - পাবলিক সাইটে ফর্ম সক্রিয় (Active) বা বন্ধ (Inactive) রাখার টগল সুইচ।

4. **১০০% ডিভাইস রেসপন্সিভ (Device Responsive)**:
   - বড় ডেস্কটপ মনিটরে দৃষ্টিনন্দন ও স্বাচ্ছন্দ্যময় অভিজ্ঞতা।
   - মোবাইল ব্রাউজারে ফুল-স্ক্রিন ফিট; কোনো অপ্রয়োজনীয় লাইনব্রেক, হরিজন্টাল স্ক্রল বা বাটন ভাঙবে না।
   - মসৃণ টাচ টার্গেট এবং বাংলা অক্ষরের নিখুঁত টাইপোগ্রাফি (Hind Siliguri / Inter)।

5. **লোকাল ডাটাবেস (Local SQLite Database)**:
   - Node.js-এর ইন-বিল্ট লাইটওয়েট SQLite ইঞ্জিন (`app.db`) ব্যবহার করা হয়েছে।
   - কোনো বাহ্যিক সার্ভার বা জটিল সেটআপ ছাড়াই স্থায়ী ডাটাবেস সংরক্ষণ।

## 🚀 কীভাবে প্রজেক্টটি চালু করবেন (How to Run)

### ১. ডিপেন্ডেন্সি ইন্সটল করুন (যদি আগে না করা থাকে):
```bash
npm install
```

### ২. সার্ভার চালু করুন:
```bash
npm start
```
অথবা ডেভেলপমেন্ট মোডে চালাতে:
```bash
npm run dev
```

### ৩. ব্রাউজারে প্রবেশ করুন:
- **পাবলিক আবেদন ফর্ম**: [http://localhost:3000](http://localhost:3000)
- **অ্যাডমিন ড্যাশবোর্ড**: [http://localhost:3000/admin](http://localhost:3000/admin)

## 🎨 থিম ও ডিজাইন স্পেসিফিকেশন

- **কালার প্যালেট**:
  - ব্যাকগ্রাউন্ড: লাইট টোন (`#f8fafc` ও `#f0fdf4`)
  - কার্ড ও কন্টেইনার: পিওর হোয়াইট (`#ffffff`)
  - প্রাইমারি এক্সেন্ট: এমারেল্ড গ্রিন (`#16a34a` / `#15803d`)
  - বর্ডার ও ডিভাইডার: সফট গ্রিন-গ্রে (`#e2e8f0` / `#dcfce7`)
- **ড্রপডাউন**: ব্রাউজারের ডিফল্ট `<select>` এর পরিবর্তে আধুনিক পপওভার স্টাইল, সার্চ ফিল্টার ও সবুজ চেকমার্ক সহ কাস্টম ড্রপডাউন।
